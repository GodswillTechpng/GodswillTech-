⚙️ GitHub Pages

To publish the website:

1. Upload "index.html" to the repository.
2. Open Settings.
3. Select Pages.
4. Choose the "main" branch.
5. Select "/ (root)".
6. Click Save.

GitHub Pages will then provide the live website address.
